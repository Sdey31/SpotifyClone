🎵 Spotify Clone

A Spotify-inspired music streaming website created using HTML and CSS. This project focuses on recreating Spotify’s modern dark-themed interface and practicing frontend design.

✨ Features

- 🎧 Spotify-inspired UI
- 🎵 Songs, albums & playlist sections
- 🌙 Dark-themed design
- 📱 Responsive layout
- 🎨 Clean and modern interface

🛠️ Tech Stack

- HTML5
- CSS3
